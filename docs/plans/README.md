# Plans

Every change to this project is planned before it is implemented. Approved plans are
stored in this directory.

Naming convention: `YYYY-MM-DD-short-title.md` (for example `2026-11-24-project-scaffold.md`).

Each plan should cover:

- **Goal** — what will be done and why.
- **Steps** — in order, with the files that change.
- **Dependencies** — any crates to add, with reasons.
- **Risks / open questions.**
